# 01 · 语言与输出约定

## 强制：中文

- **回复正文一律使用简体中文。**
- **推理过程（thinking）、计划、总结、提交信息，同样一律使用简体中文。**
- 若发现自己正在用英文推理，立即中断，并用中文重写该段推理。

## 保留英文原样

代码标识符、类名 / 函数名 / 变量名、文件路径、命令行与参数、API / DLL 名、
AHK 关键字与内置函数名 —— 这些**不要翻译**。

## 术语

沿用项目既有译名，不要另创：

| 项目用词 | 含义 |
| --- | --- |
| 组合根 | 装配 + 启动的入口区 |
| 骨架层（Kernel） | 生命周期 / 状态 / 事件 / 配置 |
| 服务层（Service） | 纯能力，无业务、无时间、无理由 |
| 功能层（Feature） | 按用户旅程排列的可插拔功能 |
| 双格式归档 | 同一次保存产出 RTF 母版 + Markdown 副本 |
| 按标签找回 | 通过文件名中的标签检索笔记 |

## 注释

新增代码的注释用中文，遵循 `SevenNote.ahk` 现有风格：`;` 开头，
区块之间用 `═══` 分隔线。
